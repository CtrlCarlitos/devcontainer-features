# Security Policy

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability**
(<https://github.com/CtrlCarlitos/devcontainer-features/security/advisories/new>).

These Features run as root inside your dev container at build time. Please do
not open a public issue for anything that lets an install script fetch or run
something it should not.

## Supported versions

Only the latest published version of each Feature is supported.
